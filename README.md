# Lissajous

Zwei Töne als Figur: Ton A schwingt auf der X-Achse, Ton B auf der Y-Achse, der
Schnittpunkt zeichnet eine Lissajous-Kurve. Einfache Verhältnisse (Oktave 1:2,
Quinte 2:3) schließen sich schnell zu ruhigen Formen, dissonante (Tritonus 32:45)
brauchen lange und werden komplex.

- **Form**: die ganze Figur, lebendig wabbelnd, schnappt beim Intervallwechsel federnd um
- **Zeichnen**: ein Punkt fährt die Kurve ab, Marimba-Schlag bei jedem Nulldurchgang einer Achse
- Zen-Modus (Taste H) blendet alles außer der Figur aus

Vite + TypeScript + Three.js, Web Audio API.

```sh
npm install
npm run dev
```
